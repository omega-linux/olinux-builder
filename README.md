# olinux-builder
This is intended to be ran inside a chroot (i normally use cubic by pj singh)
On the chroot all you need to do is run "do.sh" and let the script do its thing

You can also use this to transform your lubuntu installation into a omegalinux one, but i would recommend doing this right after you clean install the OS, and inside a TTY.
The script will still may require user intervention
